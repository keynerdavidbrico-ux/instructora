

Tecnologías utilizadas

- Python
- Flask
- PostgreSQL
- psycopg2
- Git y GitHub

 Requisitos

- Python instalado
- PostgreSQL instalado y configurado
- Git instalado

Instalación

1. Clonar el repositorio.
2. Crear un entorno virtual:

   `python -m venv venv`

3. Activar el entorno virtual en Windows:

   `.\venv\Scripts\Activate.ps1`

4. Instalar las dependencias:

   `pip install -r requirements.txt`

5. Configurar las variables de entorno necesarias para la conexión a PostgreSQL.

6. Ejecutar la aplicación:

   `python app.py`

 Base de datos

Configura las credenciales y el nombre de la base de datos según tu instalación local de PostgreSQL.
